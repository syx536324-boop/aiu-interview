# 素材

`ninja_adventure/` 为从用户提供的 E 盘素材包复制的完整原始资源，保留原目录结构、作者 README 和 CC0 许可。

常用入口：

- 地形与建筑：`ninja_adventure/Backgrounds/Tilesets/`，自然场景优先查看 `TilesetFloor.png`、`TilesetNature.png`、`TilesetHouse.png`、`TilesetWater.png`。
- 人物：`ninja_adventure/Actor/Character/`；另一套角色动画位于 `Actor/CharacterAnimated/`。
- 动物：`ninja_adventure/Actor/Animal/`。
- 界面与字体：`ninja_adventure/Ui/`。
- 声音与音乐：`ninja_adventure/Audio/`。
- 物品与特效：`ninja_adventure/Items/`、`ninja_adventure/FX/`。

作者为 Pixel-boy 与 AAA。许可全文见 `ninja_adventure/LICENSE.txt`；素材来源见项目根目录 `THIRD_PARTY_NOTICES.md`。导入清单见 `ninja_adventure_manifest.json`。

Godot 自动生成的 `.godot/` 是导入缓存，不属于源素材。
