# 0.10.2 NPC走动连续性修复

根因是workers.move直接在0.5秒在线领域tick移动碰撞体，友方enemy的物理回调又提前返回。实际GPU主场景采样中，每次位移约8.27世界像素，行走期间约3.2%的物理帧发生位移，且始终处于同一动画行。

movement.gd承接目标/速度意图，actor在物理帧中沿真实导航路线连续移动，加速及临近目标减速，使用扫掠碰撞和墙面滑动。日常、工作、婚恋跟随和出征共用此执行器；守卫寻路失败计数以真实位移为准。领域计时、资源刷新、生产、技能和战斗冷却仍只由Simulation推进，不新增第二份业务时钟。

友方和其他部落NPC统一按真实步行距离切换四向行走姿势，停下回到待机姿势。对话即停步，禁锢、死亡、房间切换和暂停不继续移动；旧档位置、路线和任务不变，临时执行意图在读档时撤销并在下一轮决策重建。

修复后12秒真实时钟采样：NPC约99%的行走帧连续位移，最大单帧约0.27世界像素，三种不同动画行正常切换。12项实际物理/动画/暂停/对话/墙体碰撞检查通过；态度125项、婚恋30项、部落/工作30项、友方行为/存档18项回归通过。完整日志在verification-0.10.2。
