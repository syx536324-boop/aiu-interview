# 0.7.8 皮装备防御

每件皮盔甲、皮护腿、皮头盔、皮靴提供1点防御，对应5%免伤。同一角色穿戴四件时防御4、免伤20%。每件之间相加；只计算正确部位已穿戴的物品。背包和柜箱内物品无防御效果，普通及赐予装备效果相同。铁装备防御仍未定义。

伤害结算为：原伤害×（1−皮装备件数×5%）×水盾倍率。水盾开启时倍率0.7，满套与水盾合计免伤44%；原伤害10实际扣5.6生命。防御由当前装备推导，无额外永久累加字段；换装、旧档恢复和复活不重复计数。

属性页显示每件皮装备防御1，以及角色总防御、装备免伤和开启水盾时的总免伤。背包描述和物品来源文档同步更新。
