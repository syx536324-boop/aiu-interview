# 0.10.8：锄头装备与脚下开垦

锄头成为普通武器。B背包选中锄头并点击“装备武器”，再到户外空地按Q，开垦人物脚下16×16世界像素的田格。E保留设施、NPC和农田灌溉交互，不开垦。

## 行为与兼容

- 开垦使用世界坐标向下取整，四个朝向结果一致，负坐标森林同样适用；连续走到相邻格后Q可以扩田。
- 背包未装备、损坏、室内、暂停、全图或面板打开时不能开垦；水域、河桥、建筑、原有田格及受保护土地沿用既有校验。
- 有效开垦消耗一次武器使用计数，40格耐久、每15次扣1格；失败不扣。田格和耐久原子保存，保存失败两者回滚。
- 锄头基础攻击1、距离30世界像素、间隔1秒，鼠标右键或J攻击；不取得斧或镐的采集能力。铁匠铺炉旁石头1修复。
- 制作配方仍为木头2＋石头1、60在线秒。旧锄头仅补齐武器耐久字段，物品数量、魔法来源和已建农田保留。

## 模块与验证

weapon_catalog与inventory定义装备与分类，homestead负责脚下格、合法土地、耐久事务，session转发Q并提供HUD快照；main仅注入equipment，界面使用既有装备按钮。
