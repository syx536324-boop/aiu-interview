# 0.10.0 NPC态度与技能行为

本版在 0.9.1 工程上实现《NPC态度与技能行为-实施方案-2026-10-14.md》首版：NPC记住玩家行为、改变态度、日常走动，并按职业使用不同战斗方式。旧有的职业、婚恋、魔法、地形、圣品与存档规则全部保留。

## 部落声誉与个人好感

每个未归附部落记录一份对玩家村落的声誉（－100～100）。首版初始值：

| 部落 | 初始声誉 | 初始态度 |
| --- | ---: | --- |
| 青木村（森林） | 0 | 中立 |
| 野蛮部落 | －50 | 敌对 |
| 云野部落 | －50 | 敌对 |

态度分段与可见行为：60～100 信任（主动招呼、允许接近重要区域、遇险援助）；20～59 友好（正常交流、放松警戒）；－19～19 中立（正常巡逻生活，不无故攻击）；－49～－20 警戒（观察玩家、进入禁区先警告、继续闯入则驱赶）；－100～－50 敌对（进入有效攻击范围且视线成立后攻击）。

归附流程优先于外部声誉：圣品被占领后，该部落成员一律按本方规则行动，不再因为旧声誉成为敌人。

事件结算：

| 成功发生的事件 | 部落声誉 | 说明 |
| --- | ---: | --- |
| 正常赠送一个面包 | ＋1 | 个人好感仍按既有规则＋5；每个部落每游戏日通过赠礼最多＋5 |
| 帮助抵御进攻 | ＋10 | 对正在进攻该部落的来犯者造成实际伤害才算；同一部落两次奖励至少间隔5在线分钟 |
| 偷取部落物品 | －10 | 从未归附他族箱柜成功取物，每操作一次；实际通知附近守卫 |
| 攻击村民 | －20 | 同一受害者60在线秒内只结算一次；多段伤害、持续伤害与未命中不会逐帧扣分 |
| 杀死村民 | －35 | 按死亡事件额外结算一次，死亡动画、读档与重复回调不再扣 |
| 攻击部落圣品 | 直接设为－100 | 守卫集中保护圣品并攻击玩家 |

个人好感的独立事件：直接受害者－30；目击者－10；受害者的配偶或亲属－40；实际被帮助的NPC＋10。全部夹在0～100并按同一事件去重。亲友关系只读取已有的婚恋数据，不会临时编造亲属。

记忆：每名NPC保留最近10条普通事件，另外单独保留最近一次严重伤害或杀害亲友事件。提示按同一NPC、同类事件至少间隔10在线秒，例如"你上次帮我们守住了村子""离祭坛远一点""有人攻击村民！"。

## 日常行为

NPC具有生活或工作、巡逻、观察、警告、接敌、准备技能、攻击、搜索、撤退、返回等状态。优先级：死亡或失控 → 保护圣品与受击反应 → 战斗与撤退 → 关系互动 → 工作或日常巡逻。农民与矿工的战斗结束后恢复原工作，不丢失背包与任务。

| 行为 | 数值 |
| --- | --- |
| 守卫日常巡逻 | 每人3～5个可通行点，到点停留1～3在线秒 |
| 发现玩家 | 普通视距160世界像素；森林部落80世界像素 |
| 中立/警戒禁区 | 圣品祭坛周围64世界像素；本方与信任玩家获准进入 |
| 警告宽限 | 5在线秒；离开禁区即解除本次驱赶 |
| 追击范围 | 不超过本部落边界外240世界像素，持续最多20在线秒 |
| 失去目标 | 到最后看见的位置搜索5在线秒，找不到就返回 |
| 返回 | 沿可通行路径返回岗位，之后恢复巡逻或工作 |
| 围攻名额 | 同一场战斗最多3名近战贴身，其余走包抄、守卫或远程支援位 |

视线被建筑或其他遮挡阻断后，NPC不会继续知道玩家位置，只有实际看见才更新"最后看见的位置"，因此不能隔墙追踪。卡住约1.5秒后重新寻路，仍不可达则搜索或返回，不会瞬移穿墙。生命低于最大生命30%时：平民、农民、矿工优先逃向本方安全位置；普通战士掩护后撤；弓箭手拉开距离；守护圣品的村长可以坚持战斗。

"呼救"以同伴支援的形式落地：中立部落成员被攻击后，同部落中能看见玩家或已知战事的成员立即接敌支援，并按上面的围攻名额表分配贴身与包抄位；同时给出"NPC：有人攻击村民！"的提示（同一NPC同类提示至少间隔10在线秒）。

## 职业招式与村长魔法

普通NPC保持无魔法，招式只消耗自身冷却与自身资源。普通攻击沿用当前职业与武器数值（弓箭手3/4/5级基础伤害仍为1/3/5）。

| NPC | 招式 | 参数 |
| --- | --- | --- |
| 平民、农民、矿工 | 逃跑、呼救；被堵住才反击 | 不获得元素魔法，反击只用已有合法攻击能力 |
| 3级及以上战士 | 冲刺斩 | 准备0.6秒，沿可通行方向前进最多40世界像素，下一次合法近战命中伤害＋2，冷却8秒 |
| 3级及以上战士 | 招架 | 减伤30%持续2秒，冷却12秒，与既有减伤来源共同遵守叠加规则 |
| 3级及以上弓箭手 | 压制箭 | 准备0.8秒，命中减速20%持续2秒，冷却10秒，消耗自己一支箭，基础伤害不增加 |
| 木系村长 | 藤蔓禁锢、快速回血 | 禁锢1秒、下一次命中汲取2生命；回血每3秒1点持续30秒 |
| 水系村长 | 水泡禁锢、水盾 | 复用现有水系主干五级与四级效果与消耗 |
| 火系村长 | 火球、持续灼烧 | 火球伤害5；灼烧每3秒扣1生命持续15秒，同来源只刷新不叠加 |
| 土系村长 | 瞬移、土房庇护 | 瞬移80世界像素；土房持续20秒，使用现有合法落点与进入限制 |

每个村长只配置对应属性的两招。主干四、五级技能消耗沿用每个技能10魔力；基础回魔沿用每60在线秒1点。NPC施法冷却：控制或攻击技能12秒，恢复或防御技能20秒，两招之间1秒公共间隔；技能本体更长时取更严格值。施法前必须有至少0.6秒的可见准备（拉弓、举武器、抬手或元素符文），玩家可以通过离开范围、遮挡或打断条件躲避。

技能效果复用既有业务实现，施法者、目标与资源归属显式传入：村长只消耗自己的魔力，缺魔力不施法；弓箭手消耗自己的箭，无箭停止射击；不会误扣当前操控角色的魔力、箭支或武器耐久。不同来源的减速与减伤按现有规则叠加，同一技能由不同NPC释放也只刷新或取较强效果。

## 存档与运行

持久化包含每部落声誉与迁移标记、每对角色好感与新增记忆、每游戏日赠礼额度、援助奖励冷却、严重事件与奖励去重标识、NPC剩余招式冷却与施法资源。旧档缺少字段时补默认值（森林0、野蛮与云野－50、记忆为空），既有好感、婚姻、职业、生命、魔法等级、魔力、背包、人口与圣品数据全部保留；迁移不重新生成村民、不恢复死亡角色、不补发箭支。

暂停、全图与离线不推进冷却、巡逻等待、搜索、追击或每日额度计时；统一使用在线时钟，继续游戏不会一次性补算离线时间。
