# 0.10.4 场景切换闪退修复

用户报告进出房屋或矿洞时闪退。两份本机Windows转储均为0xc0000005，位于0.10.3程序相同偏移。最新玩家存档只读复制到工作区隔离目录后，原始Windows程序进出灶房、离开铁匠铺时复现相同错误与退出码-1073741819。

独立新档仅开启一级被动后，也在第一次离开灶房时复现；未开启被动的新档120次切换不崩溃。编辑器诊断进一步指出branches._update_visuals访问previously freed对象。

根因是被动／增益光环原本直接挂在房间下，最后一名角色离开后，空房间释放了光环节点，但魔法模块仍保存其引用并刷新；室外分区还可能对同一视觉节点重复管理。正式Release模板没有编辑器的完整保护，形成无效对象访问并闪退。

修复：角色绑定光环改挂在角色下；魔法视觉使用streaming_exempt明确归属，不进入室外分区注册与挂载队列；短时施法／勘测视觉随房间销毁后，刷新前剔除失效引用；过期视觉隐藏并延迟释放。技能数值、业务剩余时间、物品、家具及存档格式维持原规则。入口main仍只装配，UI不持有特效生命周期。

回归入口：tests/scene_transition_probe.tscn。必须设置AIU5_TRANSITION_DIR为隔离目录，可用AIU5_TRANSITION_PASSIVE=true建立有被动光环的新档，AIU5_TRANSITION_MODE=input驱动真实E键与矿洞菜单，AIU5_TRANSITION_ROUNDS设置重复轮数。覆盖连续进出灶房、铁匠铺、矿洞，角色切换、同房多人和短时施法视觉清理。旧档用只读副本验证；原始玩家文件不作为写入目标。

测试与交付结果以VERIFICATION_0.10.4.json为准；尚未执行的检查不会记作通过。本次按本地修复交付，未提交或发布GitHub 0.10.4。
