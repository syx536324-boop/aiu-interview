# 0.10.0 世界与新手体验更新

原先待合并的世界改动已纳入0.10.0，按用户确认发布到aiu-interview。

- 断崖拥有分明岩唇、石质竖面、岩层裂隙及脚部投影，保持原碰撞、云梯开口和雾霾数值；雾仅避开不可行走的外侧岩面。
- 森林支流连续阻挡，分叉不可穿，桥面开口与显示一致，人物在桥面上；主河四桥开口也统一，NPC使用同一导航几何。
- 新档开局散落木石每点总共两批，第一次拾取后120在线秒补一次。旧档保持原有规则。其他资源的刷新概率和矿洞概率不变。
- 新手指引按真实拾取木2石4、实际完成石斧与镐子、采尽一处矿脉推进，支持收起和读档；旧档不强制，单纯拥有或赐予工具不跳过。
- 猪牛羊可用右键、J和实际箭攻击，生命10；旧档生命只下夹到10，不治疗、不复活、不补群。猪生猪肉1，牛牛皮1+生牛肉1；成年羊生羊肉1+羊毛2，幼羊保持原无掉落规则。每次击杀仅奖励25魔法点并发一次掉落。
- 沙漠枯木保留60%，其他野外可采资源80%；保留幸存ID、位置和采集进度，不使采尽资源重生，矿洞、动物、开局木石数量及单点种子/草药概率不变。

独立河桥GPU130项、密度40项通过；联合新手指引65项、断崖GPU19项、动物162项、当地防守22项通过。实际角色碰撞、桥面显示、弓箭命中与挡射线、真实在线计时和读档均已检查。导出/安装及存档完整性在本地交付证据中另行记录，源码检查不代替程序检查。

新手服务和视图位于features/onboarding，main只接线；断崖视觉在features/landscape/cliff_visual.gd，河桥几何和导航归landscape/world；资源稳定稀疏规则归world_resources/density.gd，动物和部落防守仍归各自模块。

NPC态度、防卫和招式采用本版声誉与guards状态机，详见NPC_ATTITUDE_SKILLS_0.10.0.md，不使用旧待合并版本的全族激怒逻辑。最终验收以VERIFICATION_0.10.0.json为准。
