# 沙盘上的生活：NPC态度与技能行为实施方案

日期：2026-10-14（Asia/Shanghai）

本方案用于后续代码实施，当前交付的是方案文档，尚未因此修改游戏。设计方向已由用户确认；标为“实施默认值”的细则用于补齐工程行为，不得借此改变已经确定的职业、武器、魔法、婚恋及存档规则。

## 1. 首版目标与范围

让NPC能够记住玩家行为、改变态度、日常走动，并根据职业采用不同的战斗方式。

首版必须完成：

1. 部落声望、个人好感和事件记忆。
2. 巡逻、警告、呼救、即时反击和支援。
3. 追击、失去目标后的搜索、撤退及返回岗位。
4. 战士、弓箭手的职业招式，以及村长的元素魔法。
5. 存档兼容、暂停和离线冻结、隔离验证。

首版不新建完整交易经济、任务生成系统或法师职业。友好态度先体现在对话、守卫反应、禁区许可及援助行为上；交易折扣等经济功能可在后续明确规则后加入。

实施时从最新工程及当前未提交变更继续，不以旧版本文件覆盖新代码，不撤销其他已完成或正在进行的功能。

## 2. 关系数据与初始状态

每个部落记录一个玩家部落声望，范围－100～100。同一玩家村落内的可控角色共享这份声望。

个人好感继续使用现有0～100关系数据，初始50，正常赠送一个面包增加5，婚恋门槛等沿用原规则。个人关系按稳定角色ID记录，不因切换操控角色混用。

部落声望与个人好感分开保存。个人好感高，不等于守卫允许玩家袭击该部落；眼前发生的攻击必须立即触发反击。

初始部落声望采用：

| 部落 | 首版初始声望 | 初始态度 |
| --- | ---: | --- |
| 森林部落 | 0 | 中立 |
| 野蛮部落 | －50 | 敌对 |
| 云野部落 | －50 | 敌对 |

本方成员、已经归附的成员及新出生的本方村民使用本方关系规则，不因为外部部落的旧声望再次攻击本方。占领与归附流程沿用现有规则，优先于外部部落声望。

| 声望 | 长期态度 | 可见行为 |
| --- | --- | --- |
| 60～100 | 信任 | 主动招呼、允许接近重要区域、遇险援助 |
| 20～59 | 友好 | 正常交流、放松警戒 |
| －19～19 | 中立 | 正常巡逻和生活，不无故攻击 |
| －49～－20 | 警戒 | 守卫观察玩家，进入禁区先警告，继续闯入则驱赶 |
| －100～－50 | 敌对 | 发现玩家进入有效攻击范围且视线成立后攻击 |

“5级前不会进犯”只限制主动派兵远征。巡逻、防卫、保护圣品、反击和村内支援从开局就正常运行。

## 3. 玩家行为怎样改变关系

| 成功发生的事件 | 部落声望 | 即时行为 |
| --- | ---: | --- |
| 正常赠送一个面包 | ＋1 | 收下并回应；个人好感仍按现有规则＋5 |
| 帮助抵御进攻 | ＋10 | 参与防卫的NPC记录援助者 |
| 偷取部落物品 | －10 | 目击者警告并通知守卫 |
| 攻击村民 | －20 | 受害者立即反击或逃跑呼救 |
| 杀死村民 | －35 | 附近守卫追击，相关NPC留下严重事件记忆 |
| 攻击部落圣品 | 直接设为－100 | 守卫集中保护圣品并攻击玩家 |

实施默认值：

- 每个部落每游戏日通过正常送礼获得的声望最多＋5；个人好感的既有赠礼规则不改。
- 游戏日采用游戏内昼夜计时，不采用电脑日期。暂停及离线不刷新每日额度。
- 主持婚礼分发面包、合成、开箱搬运、自动补给等不能冒充正常赠礼事件。
- 帮助抵御进攻必须有实际贡献：成功伤害正在进攻该部落的敌人，或成功治疗参战的本部落NPC。每次战斗只奖励一次＋10；同一部落两次此类奖励至少间隔5在线分钟。
- “攻击村民－20”按一次冲突中的受害者去重，同一玩家再次伤害同一NPC，60在线秒内不重复扣这一项。持续伤害、多段技能、攻击未命中不能逐帧扣声望。
- 杀死村民的－35按死亡事件额外结算一次。不得在死亡动画、读档或重复回调中再次扣分。
- 玩家指挥本方NPC发起攻击时，事件归属玩家部落；本方NPC正常抵御入侵不得误判为玩家主动攻击友军。
- 现有代码没有偷窃玩法时，只预留偷窃事件接口，不能把合法取用本方箱子、玩家自己箱子或合法战利品当成偷窃。
- 未发生正常停战的战斗期间，赠礼不能直接清空仇恨或中断守卫攻击。

个人好感的事件默认值：直接受害者在一次伤害冲突中－30；目击者－10；击杀事件使受害者的现有配偶、父母或成年子女对行为者好感－40；实际被帮助防卫或治疗的NPC＋10。全部夹在0～100，按同一事件去重。亲友关系只读取已经存在的婚恋与亲子数据，不临时为无关系NPC编造亲属。严重事件记忆另行保存，不能仅凭一次送礼就消除。

个人记忆保存事件类型、行为者ID、游戏在线时间和严重程度。每名NPC最多保存最近10条普通事件，另保留最近一次严重伤害或杀害亲友事件；避免记录无限增长。

好感和记忆应体现在短句或行动中，例如“你上次帮我们守住了村子”“离祭坛远一点”“有人攻击村民！”。同一NPC同类提示至少间隔10在线秒，避免刷屏。

## 4. 日常行为、感知与移动

NPC至少具有下列行为状态：生活或工作、巡逻、观察、警告、接敌、准备技能、攻击、搜索、撤退、返回。

优先级：死亡或失控状态 → 保护圣品及受击反应 → 战斗和撤退 → 关系互动 → 工作或日常巡逻。

农民、矿工已有工作流程继续运行，战斗结束后恢复原工作，不丢失背包物品与任务。婚礼、怀孕、接生等已有自动流程需要与战斗状态协调，不得被巡逻覆盖。

实施默认值：

| 行为 | 默认值或要求 |
| --- | --- |
| 守卫日常巡逻 | 每人3～5个可通行点；到点停留1～3在线秒 |
| 发现玩家 | 普通视距160世界像素；有效射程继续使用当前武器规则 |
| 中立部落禁区 | 圣品祭坛周围64世界像素；本方与受信任玩家获准进入 |
| 警告宽限 | 5在线秒；离开禁区则解除这次驱赶 |
| 接敌 | 必须目标存活、位置合法，并满足相应攻击的视线条件 |
| 追击范围 | 不超过本部落边界外240世界像素，持续追击最多20在线秒 |
| 失去目标 | 到最后看见的位置搜索5在线秒，找不到就返回 |
| 脱战 | 按现有攻击或受击后10秒战斗状态规则处理 |
| 返回 | 沿可通行路径返回岗位，之后恢复巡逻或工作 |

部落边界采用村庄现有范围；没有明确范围时，由该部落设施与住户所在区域生成，不能以整张地图作为追击边界。

视线被建筑或其他有效遮挡阻断后，NPC不得持续知道玩家当前位置。只有实际看到玩家才能更新“最后看见的位置”。河流、断崖、围栏及桥面通行遵守现有物理碰撞与导航规则。

NPC不能瞬间跳过障碍来追击。短时间卡住后尝试重新寻路；仍无法到达则搜索或返回。新巡逻点不能生成在水中、封闭建筑内部或不可达崖面。

附近同一场战斗最多三名近战NPC贴身围攻，其余分配到包抄、守卫、远程支援等位置，避免所有NPC重叠成一团。守卫可以呼叫附近最多三名同伴，不把全地图NPC立即传送或拉入战斗。

生命低于最大生命30%时：平民、农民、矿工优先逃向本方安全位置；普通战士掩护后撤；弓箭手拉开距离；守护圣品的村长可以坚持战斗。

## 5. 职业招式与村长魔法

普通NPC保持无魔法，魔法等级仍为现有设定。职业招式通过冷却控制，不虚构或消耗玩家魔力。

普通攻击继续沿用当前职业与武器数值。弓箭手3、4、5级基础伤害仍为1、3、5；箭支消耗、初始补给、武器距离、攻击间隔、遮挡和雾霾影响都使用既有规则。

| NPC | 首版招式或行为 | 参数 |
| --- | --- | --- |
| 平民、农民、矿工 | 逃跑、呼救；被堵住才反击 | 不赋予元素魔法；反击只能使用已有合法攻击能力 |
| 3级及以上战士 | 冲刺斩 | 准备0.6秒；沿可通行方向最多前进40世界像素；下一次合法近战命中伤害＋2；冷却8秒 |
| 3级及以上战士 | 招架 | 实施默认：减伤30%，持续2秒，冷却12秒；和现有减伤来源共同遵守叠加规则 |
| 3级及以上弓箭手 | 压制箭 | 准备0.8秒；命中减速20%持续2秒；冷却10秒；消耗一支箭，基础伤害不额外增加 |
| 木系村长 | 藤蔓禁锢、快速回血 | 复用木系主干五级与四级；禁锢1秒、下一次命中汲取2生命；回血每3秒1点持续30秒 |
| 水系村长 | 水泡禁锢、水盾 | 复用水系主干五级与四级，技能效果与消耗使用当前正式规则 |
| 火系村长 | 火球、持续灼烧 | 复用火系主干五级与四级；火球伤害5；灼烧每3秒扣1生命，持续15秒 |
| 土系村长 | 瞬移、土房庇护 | 复用土系主干五级与四级；瞬移80世界像素，土房持续20秒，使用现有合法落点与进入限制 |

每个村长只配置以上对应属性的两招，不一次性接入全部主干与36个分支。

村长必须使用自己的魔法等级、魔力上限、当前魔力和恢复计时。主干四、五级技能消耗沿用现有10魔力规则；基础回魔沿用每60在线秒1点。施法耗尽后继续采用合法的普通攻击或撤退，不获得无限魔力。

实施默认的NPC施法冷却：控制或攻击技能12秒，恢复或防御技能20秒；两招之间另有1秒公共间隔。技能本体已有更长限制时采用更严格的值。

施法决策示例：

- 木系在受伤且条件允许时治疗；目标正在逃离或需要阻止近身时用藤蔓。
- 水系在受到攻击压力时开盾；目标暴露且可命中时用水泡。
- 火系在有清楚视线和足够距离时发射火球；持续灼烧同一来源只刷新、不叠加。
- 土系被包围或低血量时向合法安全位置瞬移；需要守点或自保时才使用土房。

动作必须有可见准备：拉弓、举武器、抬手或元素符文。攻击或控制魔法准备时间至少0.6秒。玩家可以通过离开范围、遮挡或打断条件躲避；不能在没有提示时立即连放两招。

技能效果复用已有业务实现，不把玩家输入处理函数直接当成NPC技能入口。施法者、目标和资源归属必须显式传入，不能误扣当前操控角色的魔力、箭支或武器耐久。

不同来源的减速与减伤按现有规则叠加。同一技能即使由不同NPC释放也不累加，按该技能刷新或取较强效果处理。禁锢时长不相加；所有上限及特殊减伤例外继续沿用当前正式规则。

## 6. 实施结构与存档

建议模块职责如下，具体路径可适配最新工程，不为本方案进行无关的大规模重构：

| 职责 | 建议归属 |
| --- | --- |
| 声望、关系事件、个人记忆及去重 | 独立关系模块，或部落模块内的关系服务 |
| 日常状态、感知、巡逻、追击、撤退 | 部落NPC行为模块 |
| 招式选择、准备、冷却及NPC施法入口 | 战斗业务模块；复用现有技能效果 |
| 显示警告、回应、准备动作和关系信息 | UI及NPC视觉模块 |
| 注入引用、连接成功事件、启动各模块 | 现有组合入口 |
| 保存和恢复 | 既有存档服务，通过模块导出及恢复接口接入 |

UI只显示快照并发送玩家操作，不在UI计算声望、伤害或战斗计时。

关系事件接入成功动作：赠礼交易成功、实际造成伤害、确认死亡、成功治疗、合法偷窃等。材料扣除、关系变化与必要状态保存应属于同一次事务；保存失败时整体回滚，读档不得重播扣分或奖励。

持久化至少包括：

- 每个部落的声望及初始迁移标记。
- 每对角色的已有好感与新增记忆。
- 每游戏日送礼声望额度、援助奖励冷却。
- 严重事件与奖励去重所需标识。
- NPC剩余招式冷却、施法资源及必要的岗位信息。

旧档缺少字段时安全补默认值：森林声望0，野蛮及云野－50，记忆为空；既有好感、婚姻、职业、生命、魔法等级、魔力、背包、人口和圣品数据保留。

迁移不能重新生成村民、恢复死亡角色、补发箭支或恢复已经消耗的资源。临时追击目标失效时返回岗位，不把失效引用序列化为可执行目标。

暂停、全图和离线不推进冷却、巡逻等待、搜索、追击或声望额度计时。统一使用游戏在线时钟，不能同时由独立帧回调和统一时钟重复推进。

附近NPC约每0.3秒决策一次；统一时钟为0.5秒粗tick时可以按0.5秒执行，移动仍沿用正常物理帧。远处NPC按1～2在线秒降低更新频率，不能因此冻结已发生的战斗或错误补算离线时间。

## 7. 推荐实施顺序

1. 核对最新源码、当前NPC状态和已存在的职业、魔法、关系及存档接口，保存本次改动前的必要备份。
2. 实现声望、事件记忆、成功事件去重与存档迁移。
3. 实现巡逻、警戒、呼救及即时反击，先验证5级以下仍可防卫。
4. 实现追击边界、视线、搜索、撤退及返回岗位。
5. 实现战士与弓箭手招式；再接入村长的两种元素技能。
6. 补充提示和准备动作，检查主视图、菜单与多NPC场景的可读性。
7. 运行隔离验证、实际程序检查及必要的性能对照，再完成本地副本同步和交付记录。

## 8. 验收标准

必须使用隔离存档，不在真实玩家存档内攻击、赠送、生成NPC或推进测试时间。

关系与防卫：

- 森林中立NPC会巡逻，正常接近不无故攻击；闯入祭坛禁区会警告。
- 1级玩家攻击NPC，受害者即时反击或呼救，同伴支援；不能因为玩家未到5级而冻结反击。
- 敌对战斗NPC在目标进入有效攻击范围、视线成立时正常攻击。
- 送面包个人好感只增加5，部落声望增加1；当天赠礼声望累计不超过5。
- 多段伤害、持续灼烧、死亡回调、读档和保存失败不会重复扣声望或奖励。
- 声望跨越阈值后，下一次行为判断采用新态度，NPC反馈与实际行为一致。

移动与战斗：

- NPC可以巡逻、沿桥过河和绕过障碍，不穿水、穿墙、穿崖或从桥下走过。
- 丢失视线后只能搜索最后看到的位置，不隔墙追踪玩家。
- 追击超时或超界后返回岗位，恢复工作或巡逻。
- 战士冲刺遵守真实碰撞，不能冲过河流、断崖或墙体。
- 弓箭手消耗自己的箭，无箭时停止射击；压制箭命中才施加减速。
- 村长只消耗自己的魔力，缺魔力不施法；准备动作、效果和冷却一致。
- 玩家与NPC同类技能都遵守现有减速、减伤、禁锢及同来源限制。
- 圣品被攻击时触发明确防卫，占领及归附后不会残留敌对目标。

存档与运行：

- 旧档迁移保留所有既有玩家及NPC数据，不补血、不复活、不重发物资。
- 保存重启后关系、记忆、每日额度及剩余冷却保持正确。
- 暂停、全图、离线不推进NPC计时；继续游戏不一次性补算停留时间。
- 实际Windows程序能运行上述行为，没有脚本错误或无限寻路。
- 对比改动前后同场景、同人数的处理耗时，记录差异；不无依据保证所有场景恒定60帧。
