# 0.10.1 友方平民日常走动修复

0.10.0开局阿林与小满属于友方平民。原有guards排除友方，workers只处理农民和矿工，war没有目标时立即返回，人物自身也已交给tribes接管，因此两名平民永远待命。隔离复现中推进30在线秒，两人的最大位移均为0。
