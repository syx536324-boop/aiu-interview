# 0.9.1 合成在线计时修复

工作台确认制作后，剩余时间曾一直停在60秒。原因是Production由统一Simulation时钟推进，但没有自己的_process回调，也未显式启用process；时钟以is_processing检查领域开关时跳过了它。Foraging散落材料补充存在相同遗漏。

两模块start现明确启用领域开关，仍只由统一时钟推进，不增加独立帧回调。制作60在线秒、冶炼30在线秒和散落材料120在线秒不变。合成菜单打开、离开工作台或切换制作角色时继续；全图、暂停和离线冻结。已保存的任务按剩余时间继续，材料仅支付一次；满包成品保留待领。

## 验证

- tests/crafting_clock_probe.tscn使用真实游戏帧，源码无渲染检查62项、实际GPU画面检查63项通过；不调用production.elapse或Simulation._process。
- 实际倒计时60→约57.9秒，界面进度约2.05秒；冶炼30→约29.5秒，材料补充120→约119.5秒。
- 覆盖菜单持续计时、Esc和M暂停、真实释放并重建游戏后的读档、离线不补时、单次成品、满包暂存及领取、冶炼、资源补充。
- 原crafting_smoke及smith_smoke通过，覆盖材料事务、存档失败退款、背包及工作台规则。
- 读档时间检查容许JSON浮点往返的1毫秒误差。

安装包和本机安装后的实际程序结果在交付证据中另行记录，源码检查未代替导出程序检查。
