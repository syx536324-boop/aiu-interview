# 参与开发

欢迎通过[GitHub Issues](https://github.com/syx536324-boop/aiu-interview/issues)反馈问题，或提交仅修改`aiu5/`目录的Pull Request。描述游戏版本、复现步骤、预期与实际结果；截图有助于定位界面及碰撞问题。

开发环境及许可范围见[开源说明](OPEN_SOURCE.md)。新增功能放在对应`features/`模块，保持`scenes/main.gd`负责装配；模块接口变化时同步更新本模块README。游戏数值或存档规则变化时说明兼容处理。

选择与改动相关的现有`tests/`场景验证，不使用真实玩家存档做攻击、资源消耗或时间推进测试。按场景要求设置`AIU5_PROBE_DIRECTORY`等隔离目录，提供执行结果；不要把个人存档、账户凭据、缓存、模型权重或原始训练图片加入提交。

提交自己有权提供的内容，注明新增第三方素材及依赖的来源和许可证。贡献的原创代码沿用本项目AGPL-3.0-only许可证，已有第三方声明保持原样。
