## 开发与版本管理

当前没有运行依赖或启动命令。后续添加代码时，请同步补充依赖安装、配置和启动说明。

本项目与 aiu、aiu2、aiu3、aiu4 并列，由仓库根目录的 Git 统一管理，提交至 `main` 分支。

在仓库根目录提交 AIU5 的改动：

```powershell
git add aiu5/
git commit -m "Update AIU5"
git push origin main
```

环境文件、密钥、本地依赖、缓存、日志和构建产物由 `.gitignore` 排除。
