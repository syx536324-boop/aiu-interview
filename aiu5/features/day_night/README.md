# 昼夜轮换

`cycle.gd`拥有在线时间、天数和世界色调。现实60秒=游戏1小时，1440秒=24小时一轮。新存档和无该字段的旧存档从第1天08:00开始；黎明05–07、白昼07–17、黄昏17–20、夜晚20–05，色调在关键小时之间平滑过渡。夜间保留可见亮度，屋内更亮，UI保持正常颜色。

`start(session)`、`advance(delta)`、`snapshot()`、`export_state()`、`restore(data)`。统一simulation在线时钟推进，存档保留不足一秒进度；全图、Esc暂停、祭台摄像头、开始菜单和离线不推进。UI仅读取session快照。没有额外改变敌人、作物、健康或睡眠规则。
