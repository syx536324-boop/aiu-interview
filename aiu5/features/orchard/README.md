# 苹果树

`orchard.gd`负责种植门槛、材料、结果、在线计时和事务保存；`apple_tree.gd`只绘制像素树冠、红苹果、树苗与树干碰撞。

新旧存档为主村补齐3棵成年树，森林部落周边补齐20棵。每棵初始有3个苹果；靠近后交互采摘。采完5在线分钟再次结3个，未采摘不累积。额外种植要求当前角色已觉醒木系且魔法等级至少1，消耗背包1个苹果。手机“更多→种果树”，电脑版源码O，在角色面朝方向的空地种下幼树，5在线分钟长成并结出第一批3个苹果。房屋、河桥、道路、农田、人物和已有障碍物会限制位置。

`Session`路由交互；`Simulation`只转发在线时间；`Persistence`保存每棵树的坐标、生长剩余时间、结果剩余时间和成熟果实。暂停、全图、停服、离线不会推进；背包满不扣果实，保存失败回滚果实、材料和树。果树占地也供野外资源模块查询，避免以后刷新资源重叠。

验证入口：`res://tests/orchard_probe.tscn`，必须设置独立的`AIU5_BENCH_DIR`；触屏和原生相机回归为`res://tests/mobile_probe.tscn`。
