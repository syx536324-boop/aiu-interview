# 21格背包、柜箱与物品事务

皮制和铁制防具每格1件，沿用普通储物与转移。使用装备打开该角色属性页；穿戴/卸下由magic处理，装备槽进入magic快照。旧armor/leggings/hood/boots迁移为对应皮制件并保留来源。

`inventory.gd` / `.tscn` 以稳定角色ID管理独立21格背包，以家具ID管理独立21格柜箱。`open_bag` / `open_container` / `close` 控制窗口；`slot_clicked` 完成整理、合并、交换和Shift快速存取，空间不足保留余数。`snapshot`、`changed` 和 `message` 供会话和界面使用。

`catalog.gd` 定义原始工具、面包、书本、生猪肉、木头，以及空/满水桶、熟猪肉、工作台、围栏、小麦种子、水稻种子、小麦与稻谷。原`seeds`ID保留并改名为小麦种子，避免旧背包/柜箱数量丢失。种子及谷物每格上限99；新角色两类种子各3，已有补给不重发。`exchange(id, costs, rewards)` 先在副本扣除与添加，材料不足或容量不够不改变原背包；领域模块完成后由会话持久保存。`grant_supplies` 为新旧角色按项目一次性补给，失败项目可在下次启动重试；旧祭台回退同样检查补给。`commit_resource_reward` 保持原有奖励/进度同次保存及失败回滚。

`store_layout` 保存室内外家具；`export_data` 从 `session_provider` 获取完整快照，`save_state` / `write_file` 使用临时文件刷新替换。`start` 兼容版本1/2，`apply_data` 供祭台恢复库存。`AIU5_STATE_PATH` 隔离测试文件；完整续玩协调归 `features/persistence`，状态、烹饪及农田规则分别归对应功能模块。

`water_catalog.gd` 定义桶的0/4至4/4及木杯的空/满状态、每次饮水恢复4格和容器转换；供catalog、survival、homestead与图标使用。部分桶以独立物品ID保存，每格1个，不额外占用水量格；原`bucket`/`water_bucket`分别继续代表空/满桶。三种部分桶、空木杯和满木杯进入普通转移/序列化流程，避免额外元数据在储物时丢失。木质水杯由工作台木头1制作或摄像头赐予，不再自动补给。


小麦和稻谷可作为一份动物饲料；石头和铁矿每格99。工作台配方与喂食均调用exchange原子消费，UI不计算材料。镐子由工作台木头1和石头2合成，旧存档已有镐子保留。

建筑更新：construction拥有建筑台转化、动态房间与建筑生命/百分比减伤，production拥有T合成、V铁桶装沙与灶台30秒冶炼，combat拥有J弓箭及3名击败后不刷新的外部落敌人。UI通过workshop快照/操作信号请求，不计算材料与伤害；main仅组合。动态房屋/废墟加入world.homes及全图名字缓存，自建房屋附近保留3×3碰撞/敌人，远处停用；箭楼屋顶在世界坐标显示并可射箭。建筑、冶炼与敌人状态同时进入自动/祭台存档，旧档缺字段兼容。矿洞624×264保留原矿脉并新增30处铁矿，镜头跟随；详细接口和操作见新模块README与根README。

## 西岸森林接入

新增人参(ginseng)、灵芝(reishi)、枸杞(goji)、桑叶(mulberry_leaf)、大补汤(restorative_soup)、补气汤(qi_soup)，各格上限99，使用原21格背包/柜箱与存档。汤剂有独立喝汤按钮和图标；草药屋配方返还wooden_cup。


武器与工具更新：weapon_catalog定义镐子1、木剑1、石剑3、铁剑5、石斧2、铁斧4、弓1的基础攻击及分类。单格装备支持这些武器，equip_weapon仍原子交换并持久化。木斧从物品表移除，inventory._sanitize_slots和magic.restore_state将旧木斧转换为石斧。必须装备镐子采矿、装备斧砍树；桑树空手E采叶，持斧E砍树，其他武器不能采叶。森林树木沿用每2次1木头、4次砍完，resource_hits保持稳定ID，重载不复原。J近战29单位、0.6秒间隔、视线和朝向检查；弓每次成功发射扣背包1箭，失败不扣；X拆自建房按当前斧攻击和房屋防御计算。

## 武器实例保存

武器单格记录增加durability、uses字段，sanitize时保留或按40/0补齐；新制作的武器满耐久。swap_weapon返回被选中武器的wear并将旧装备连同wear移入背包，缺物品或满包不改变状态。同款武器不可合并，普通移动、Shift快速存取、柜箱和角色转交搬运整份记录，避免重建物品重置耐久。durability_smoke覆盖同款选择、交换和重载。

## 皮革与新防具

皮革每格99，牛击杀获得1；皮/铁盔甲、护腿、头盔、靴均每格1，可储存、转交、穿戴和保存。铁制原料为现有粗铁，不新增同义材料。普通新防具不自动附加魔法；摄像头赐予实例保留魔法来源，转移和穿戴不改变来源。

分类由categories.gd显式覆盖全部物品；B顶部可按食物、武器、装备、工具、家具、材料、草药、种子、书籍筛选，不重排真实21格，点击携带原槽位索引。动物为场景实体，不放进包。新增刀/碗/剪刀/苹果/胡萝卜；刀纳入装备耐久，苹果/胡萝卜各恢复饥饿2。exchange第四参数apply=false只校验，不改变包或发信号，供制作确认前容量校验。

## 新角色与兼容

新角色初始只补给小麦种子3、水稻种子3，不再赠送工具、食物、书本或家具；其他物品制作、采集或赐予。旧档已有物品和数量保留，不追扣。旧四件基础装备在背包、容器和穿戴时迁移为皮制对应件，魔法来源保留。旧刀ID knife作为石头刀，保留耐久。
