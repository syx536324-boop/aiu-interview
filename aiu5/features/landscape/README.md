# 扩展荒漠地理

村落坐标保留，地图扩大为2400×1600（原面积约6.67倍）；中部、南部空地供后续部落扩展。西边河流沿地图边缘流过，村落附近较窄，南侧拓宽；四座木桥可通行，河岸E装满桶杯。东边高山作为不可穿越的地形，东山矿洞位于山脚，沙路延长至矿洞与南部。

`landscape.gd.start(world)` 建立河流、高山、桥梁与祭祀广场的真实碰撞；`water_target(at)` 将河岸互动点移到当前河段。`protected(bounds)` 让锄地和部署保留河岸、桥梁、高山及祭台广场。共享常量在`layout.gd`，绘图独立在`view.gd`。祭台中心和存档位置保留，外围扩为148×104铺石广场并加两根石柱，中央石台加宽。地图全景为HUD留出空间。地理与采矿联动验证见`tests/mining_smoke.gd`、移动/碰撞回归见`tests/village_smoke.gd`。

## 局部绘制

view.render_region由streaming按活动区域更新，远处山、河和广场跳过绘制。少量全局地理碰撞常驻以保留通行约束。全图使用独立简化纹理，不依赖放大真实世界场景。

## 西岸森林接入

西侧边界移到-2400，现有四桥连通森林；river取水目标按角色所在河岸定位，林西岸也可给桶与杯补水。森林地图规则见features/forest。

绘制森林中部青木祭台铺地，protected(bounds) 保护该祭台广场，避免玩家部署或开垦遮挡设施。
