# 动物与掉落

`livestock.gd` 管理猪、牛、羊的成长、喂食、配对繁殖与持久化；`herd_catalog.gd` 定义种类和掉落。初始羊为成年公母各1，旧存档通过herd_version=2补齐一次。幼崽300在线秒成年，一份小麦/稻谷缩短60秒；成年同种异性均喂食后繁殖，300秒冷却。

击杀猪掉生猪肉1；牛掉皮革1、生牛肉1；成年羊掉生羊肉1、羊毛2，幼羊不掉肉和羊毛。鸟狗保持环境动物且不繁殖，现可被武器击杀。所有击杀由combat发放25魔法点，掉落、死亡、武器耐久、点数一起保存；满包或保存失败不丢动物、不奖励点数。保留种畜可持续繁殖。

`damage_animal` 返回伤害/击杀结果，事务由combat拥有；`damage_cow` 保留兼容入口。箭记录射手ID，切换角色后奖励仍归射手。

## 0.8.1接口与规则

牛死亡掉cowhide1＋beef1；成年羊仍可死亡掉wool2＋mutton1，也可经production.scissors_tools无伤剪毛、每羊300在线秒。sheared元数据只影响外观，实际采集资格和冷却由制作模块持久化。
