# HUD、角色、背包与布置界面

`attributes.gd`新增C名单每行“属性”入口，含魔法等级/技能树导航，人物形象两侧四格装备、经验进度条、五主干与三个待定义分支。祭台R另开四系选择并显式确认；装备、觉醒、领取和点亮只发信号给session，由magic校验和保存。读取attributes/awakening快照，关闭时不刷新属性内容，样式缓存复用，人物贴图只在换人/打开时更新。Esc先关闭装备选择，再返回属性/角色列表。

`hud.gd` / `.tscn` 通过 `bind_session` 订阅快照，显示生命/饥饿/饥渴/健康/魔力五条状态，生命与魔力上限读取快照、疾病与低健康倒计时、设施提示和角色位置。C面板显示每人的五项数值与正在操控/状态锁定/已阵亡，按名单生成头像按钮并禁用阵亡者，姓名编辑通过信号请求会话处理。

`belongings.gd` / `.tscn` 展示独立21格背包/柜箱，`slot_requested` 交给库存，`use_requested` 交给会话食用/饮水/锄地/播种/部署；家具选择、旋转、回收和关闭也经信号传递。户外布置栏只显示工作台和围栏，屋内显示全部可布置类别。`item_icon.gd` 绘制物品像素图标。UI只呈现快照和动作，不计算消耗、疾病、容量、碰撞或存档。

作物信息由会话快照的`crop_detail`提供，田旁显示物种、四阶段进度和距成熟倒计时；G提示根据生长/成熟状态变化。背包种子按钮显示“选择种子 / 播种”，四字物品名缩为9号适配格子，完整名称与说明可悬停查看。小麦和水稻种子袋、谷穗各有不同像素图标。

会话提供`water_text`，HUD显示随身最高桶水量及满木杯数量；背包各桶名称标明3/4、2/4、1/4，图标液面与四格标记对应水量。空/满木质水杯绘制木纹、杯柄和水面；饮水按钮分别显示“饮水（1/4桶）”或“饮水（一杯）”。水量与饥渴计算仍由领域模块负责。

## 避免重复更新

相同数值的状态条不重复重绘，关闭的角色面板不更新各行。独立全图由streaming提供，HUD不承担远区场景加载或游戏时间计算。

祭坛储物窗口读取offering快照，展示阵亡目标下拉框与献祭按钮，只发出sacrifice_requested(target_id)；领域服务校验距离、祭品、目标与存档状态。非祭坛柜箱不显示献祭控件。目标列表刷新保留所选稳定ID，存取不会自动献祭。

建筑更新：construction拥有建筑台转化、动态房间与建筑生命/百分比减伤，production拥有T合成、V铁桶装沙与灶台30秒冶炼，combat拥有J弓箭及3名击败后不刷新的外部落敌人。UI通过workshop快照/操作信号请求，不计算材料与伤害；main仅组合。动态房屋/废墟加入world.homes及全图名字缓存，自建房屋附近保留3×3碰撞/敌人，远处停用；箭楼屋顶在世界坐标显示并可射箭。建筑、冶炼与敌人状态同时进入自动/祭台存档，旧档缺字段兼容。矿洞624×264保留原矿脉并新增30处铁矿，镜头跟随；详细接口和操作见新模块README与根README。


武器框：画面下方偏右单格武器位，每个角色独立保存。点击空框打开背包，选镐子、斧、剑或弓后点“装备武器”；点击已装备框卸回背包（背包满则保留）。J使用已装备武器进行攻击。magic.equip_weapon负责原子物品交换及保存失败回滚，weapon_snapshot向HUD提供显示数据，session协调操作，main只连接信号。旧存档缺weapon时为空，背包内弓箭仍保留。


武器与工具更新：weapon_catalog定义镐子1、木剑1、石剑3、铁剑5、石斧2、铁斧4、弓1的基础攻击及分类。单格装备支持这些武器，equip_weapon仍原子交换并持久化。木斧从物品表移除，inventory._sanitize_slots和magic.restore_state将旧木斧转换为石斧。必须装备镐子采矿、装备斧砍树；桑树空手E采叶，持斧E砍树，其他武器不能采叶。森林树木沿用每2次1木头、4次砍完，resource_hits保持稳定ID，重载不复原。J近战29单位、0.6秒间隔、视线和朝向检查；弓每次成功发射扣背包1箭，失败不扣；X拆自建房按当前斧攻击和房屋防御计算。

## 耐久显示

durability_bar只按weapon_snapshot.wear绘制武器框内40格条；0格显示“损坏”。HUD悬停和背包/柜箱武器格悬停展示耐久与本格次数，选中武器也可查看同样信息。界面不修改耐久，使用仍由session与领域模块协调。

## 铁匠铺与材质选择

Workshop按recipes数量动态扩展滚动按钮（保留原10个初始按钮），支持背包21件加装备1件的修复及8种合成，不截断列表。Attributes增加材质下拉选择，缺物品项禁用，替换/卸下交由magic处理；悬停展示实际装备名。item_icon用棕皮/灰铁区分防具并绘制皮革，UI不实现材料扣除或修复规则。

workshop.gd顶部分类，左侧可合成物品，右侧材料需要/拥有与60秒说明，右下确认合成；选择与确认分离。snapshot提供分类/材料/任务，周期刷新保留选项，主题仅在选中状态变化时更新。belongings.gd筛选只改变显示与槽位映射，不变更库存。

## 来源与成就

背包选中详情显示自身来源/配方，悬停仍显示来源、类别和耐久。C→属性新增成就页，展示具体成就待定与100点奖励规则；未觉醒经验显示累计点数。取消领取免费基础装备按钮。

魔法图标：gift_icon_atlas按固定18类映射提供透明符文纹理；item_icon.set_record读取赐予来源。背包/柜箱、装备、HUD武器位及识别候选共用此图集，普通实例保留原绘制。magic快照提供magical布尔值，UI不改来源或数值。

魔力上限来自后端max_mana快照，HUD、C名单与技能树显示当前值/上限。status_bar使用最多十段的比例，505上限仍可读，不按505格绘制。
