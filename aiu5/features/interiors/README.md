# 房间、木家具与布置

`interiors.gd` / `.tscn` 管理八间独立房间，`enter` / `leave` 安全挂接居民，`focus` 只显示当前房间并切换相机。`layout.gd` 定义不同草席、地板与54件初始家具/灶台；所有新增家具都需背包中对应成品；移动和回收已有家具保留来源，灶房泥砖灶台固定不可移除。

`room.gd` 提供碰撞/导航、`nearby`、`placement_error` 和家具增删移动/导出接口。`furniture.gd` 原生绘制木家具、工作台、围栏和灶台。柜箱以稳定ID关联21格内容，取空才允许删除。家具不覆盖门口、其他家具或村民，并保留通向出口的路；草席可行走。

`furniture_editor.gd` 由会话F/R/Delete/Esc和UI信号驱动，可同时适配室内room与户外grounds。工作台和围栏部署消耗背包，回收返还，移动不消耗。预览不改原碰撞，确认后保存布局。完整存档恢复室内/户外位置与家具布局，见 `features/persistence`。


special_rooms注册特殊房间工厂，矿洞复用enter/leave/focus/context及稳定room_id。地下不能布置家具；普通室内工作台nearby返回workbench，由session交给mining处理配方。

## 按需房间

未进入的房间不创建，离开无人房间时导出布局到共享layout_overrides后释放；柜箱内容由inventory按稳定ID保留。有其他角色的房间退出场景树，选择该角色再挂接并恢复相机。special_rooms支持矿洞相同生命周期。室内家具初始化后一次建立导航，预览按网格/朝向/revision及0.2秒缓存，确认操作重新校验。

建筑更新：construction拥有建筑台转化、动态房间与建筑生命/百分比减伤，production拥有T合成、V铁桶装沙与灶台30秒冶炼，combat拥有J弓箭及3名击败后不刷新的外部落敌人。UI通过workshop快照/操作信号请求，不计算材料与伤害；main仅组合。动态房屋/废墟加入world.homes及全图名字缓存，自建房屋附近保留3×3碰撞/敌人，远处停用；箭楼屋顶在世界坐标显示并可射箭。建筑、冶炼与敌人状态同时进入自动/祭台存档，旧档缺字段兼容。矿洞624×264保留原矿脉并新增30处铁矿，镜头跟随；详细接口和操作见新模块README与根README。

## 西岸森林接入

新增herb_house独立木屋布局，含可自由布置的工作台、柜箱、桌椅与草席。工作台旁E/T转到汤剂界面；房间缓存、储物及家具保存继续走原接口。

新增铁匠铺及青木村四间房的独立布局、家具ID与21格容器，沿用 enter/leave 与按需释放。铁匠铺含冶炼炉和工作台；青木草药屋含汤剂工作台，三间住房含床、木柜、桌椅、箱子与草席。

## 家具收费与回收

新增床、柜、桌、椅、箱都需要背包成品，不能免费生成。移动/旋转不耗物；部署消耗1个记录，回收返还实际记录并保留摄像头来源；预置旧家具可回收为对应物品。柜箱先取空，工作台先完成队列，公共工作台固定。所有部署与回收原子保存，失败还原布局和背包。
