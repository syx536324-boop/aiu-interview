# 起步材料与公共工作台

取消开局工具后，`foraging.gd` 在赤沙村、青木村各提供预置工作台与散落木头/石头。靠近材料E空手拾取，120在线秒后补充。预置工作台可搬动或回收；可制作自己的工具和工作台。

`start(session)` 注册场景和交互点，`gather(id)` 原子保存拾取，满包或存档失败保留材料；`elapse(delta)` 由simulation时钟推进，`export_state/restore` 接入完整存档。只读重启不会重置资源倒计时，暂停和离线不推进。组合入口不承载经营规则。

## 0.9.1在线计时修复

Production及Foraging由统一Simulation时钟驱动；start显式启用领域的process标志。这两个节点无需自己的_process回调，避免重复计算时间。tests/crafting_clock_probe.tscn以真实帧检查菜单中的进度、冶炼、资源补充、暂停及读档，不直接调用elapse。

## 0.10.0 新存档补充上限

新建starter_v2存档的每处开局木石拾取点只有初始及120在线秒后的补充，共两份；采完第二份永久消失。`batch_limit` 与 `taken` 保存在自动及祭台快照；已有存档缺字段保留无限补充，不改变其历史资源。其他树木、矿脉、草药和种子规则不受影响。`gathered(item,actor_id)` 在拾取事务中供新手指引订阅，满包或保存失败不推进目标或消耗份额。


0.10.6：开局预置工作台允许移动与回收，_build会跳过grounds.retired_fixtures内的ID，资源补充、读档和重新部署不会额外生成已回收的工作台。旧档缺少移除记录沿用原有预置布局；开局木石补充轮次不受影响。
