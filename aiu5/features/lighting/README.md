# 火把

`torches.gd.start(session)`装配独立火把格，`equip(id, index)`交换真实实例并原子保存，`ignite(id)`供篝火和火系三级技能在同一事务内使用。`advance(delta)`由在线模拟驱动，只有操控中的存活角色、点燃的已装备火把消耗耐久。

工作台煤矿1＋木头1，制作60在线秒。初始熄灭，累计燃烧600秒报废；每次点燃燃烧300秒后熄灭，再次点燃不恢复耐久。卸下自动熄灭，暂停、离线、死亡及未操控角色冻结时间；实例与计时随背包、容器、角色装备及存档保存。PointLight2D纹理为80×80，texture_scale=1，表示世界像素；镜头缩放不改变照明世界尺寸。
