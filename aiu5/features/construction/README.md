# 自建房屋与箭楼

`catalog`定义96×80用地、四类配方、生命与百分比防御。木屋木头100，50生命/0防御；石屋石头100＋木头50，100生命/10防御；铁屋5桶沙子＋粗铁50＋石头50＋木头50，200生命/20防御；箭楼木头100＋石头100，暂定100生命/10防御。伤害=原伤害×(1−防御/100)，不作整数取整。

`construction.start(session)`接入；`build(actor, bench, kind)`从该角色背包投入完整配方，消耗建筑台并注册动态房屋、入口与按需房间。`hit(id, raw)`应用减伤，`demolish(actor)`为门口X木斧拆毁（每下原伤害10）。`export_state/restore`保存稳定built:ID、位置、种类和生命。建筑台只在户外F部署，固定朝向，部署时预留完整用地，不能用旋转使最终房屋越界；未建成可移动和回收。

普通自建屋含草席和木床/箱/桌/椅，可使用原家具系统自由布置；三材质外观不同。生命归零撤出屋内角色，变为无实体阻挡的废墟，保留可搜寻入口和原房间布局、容器，以便取回物品。不退款建材，暂不提供修复升级。原固定村庄建筑保持原交互。

`roof.gd`复用房间移动/退出契约，在真实世界坐标绘制顶部。进箭楼直接登顶，周围世界仍显示，附近3×3碰撞与敌人运行；鼠标瞄准J射箭，阶梯E下楼，顶部不开放家具布置。普通自建屋内保留附近敌人/建筑碰撞，以允许围攻；远区继续分区停用。

规则通过session协调，main只组合。生产事务提交失败恢复完整快照，撤销建造/伤害和材料变化。自动退出续玩与祭台回退均包含建筑状态，旧档缺字段时无自建建筑。动态建筑和废墟进入独立全图名称缓存；世界资源生成避开其用地。


武器与工具更新：weapon_catalog定义镐子1、木剑1、石剑3、铁剑5、石斧2、铁斧4、弓10的基础攻击及分类。单格装备支持这些武器，equip_weapon仍原子交换并持久化。木斧从物品表移除，inventory._sanitize_slots和magic.restore_state将旧木斧转换为石斧。必须装备镐子采矿、装备斧砍树；桑树空手E采叶，持斧E砍树，其他武器不能采叶。森林树木沿用每2次1木头、4次砍完，resource_hits保持稳定ID，重载不复原。J近战29单位、0.6秒间隔、视线和朝向检查；弓每次成功发射扣背包1箭，失败不扣；X拆自建房按当前斧攻击和房屋防御计算。

## 拆房耐久

玩家X拆房调用hit(id,raw,consume_tool=true)，将已装备斧的1次使用与建筑伤害一起提交。损坏斧和失败提交不扣；敌人攻击建筑默认consume_tool=false，不影响任何玩家武器。construction_smoke验证25次拆房后39格、本格10次。
