# 自动续玩与祭台回退

会话快照`magic`保存各角色元素、等级、经验、技能点、已点亮节点、装备和一次领取标记，恢复交由magic解释。旧档缺省未觉醒/空装备。魔法服务提交前保留自身和背包副本，写入失败一起撤销。单人复活保留魔法进度，祭台回退恢复全局快照。

`checkpoints.gd` 的 `start(session, vitals, homestead, grounds)` 在各模块准备后恢复完整会话，并安装库存序列化回调。`capture_session` / `restore_session` 负责居民房间和坐标、圈门、猪、名字、状态与计时、农田和烹饪；库存保存背包、柜箱、室内外家具、枯木和一次性补给标记。重载时先从缓存房间安全移出居民，再重建房间，维持稳定角色引用。

`save_now()` 每15秒、经营操作后及正常窗口关闭时调用；失败保留窗口供重试。`save_checkpoint()` 单独写 `.altar`，初始游戏建立回退点，祭台E更新。单人死亡切到存活角色，全部死亡延迟到安全帧 `restore_checkpoint()` 恢复整个快照，再更新自动存档。退出到再次启动之间不累加真实墙上时间。测试路径来自 `AIU5_STATE_PATH`，关闭通知双进程测试见根README。

农田快照包含物种、生长的部分秒数、阶段和各角色所选种子，恢复时由homestead解释。回退至更新前的旧祭台存档后检查一次性补给标记，为未领的角色发新种子，已有项目不重发；满包项目留待下次启动。


完整快照新增livestock稳定动物记录和mining矿脉进度。恢复先迁移地表矿脉，再按特殊房间工厂重建地下，最后恢复动物并删除祭台存档之后出生的动物；旧猪数组迁移保留位置，只加入一对初始牛。新状态由各模块解释。

## 分区兼容

capture_session先flush在线时钟，农田和动物导出时结算待处理时间；人物、动物、部署物即使退出场景树仍按稳定ID保存。房间布局包含已释放房间的共享记录，恢复可处理暂时脱离树的房间。全图暂停期间仍响应正常关闭窗口的保存通知；退出不保存“正在看地图”的暂停状态。streaming_smoke及quit_save_smoke的paused/verify双进程覆盖这些路径。


## 多存档

开始界面为每份村落设定独立AIU5_STATE_PATH与AIU5_PROFILE_PATH，自动、祭台和姓名状态互相隔离。capture_session保存settlement村落类型，构建场景之前由save_slots/profile读取；旧快照默认expanded。祭坛容器作为普通共享库存进入当前与回退快照。暂停菜单先保存再退出或返回开始界面，失败保留游戏；暂停期间正常窗口关闭也保存。


完整快照resource_world记录世界种子、生成版本与迁移避让的资源ID；采集delta继续在harvesting与mining.progress。恢复先加载现有布局、农田和采集进度，再重建资源缓存；旧祭台快照缺少生成字段时保留此存档种子，不重新随机。区块卸载只删除节点，自动存档与祭台回退均包含远区进度。

建筑更新：construction拥有建筑台转化、动态房间与建筑生命/百分比减伤，production拥有T合成、V铁桶装沙与灶台30秒冶炼，combat拥有J弓箭及3名击败后不刷新的外部落敌人。UI通过workshop快照/操作信号请求，不计算材料与伤害；main仅组合。动态房屋/废墟加入world.homes及全图名字缓存，自建房屋附近保留3×3碰撞/敌人，远处停用；箭楼屋顶在世界坐标显示并可射箭。建筑、冶炼与敌人状态同时进入自动/祭台存档，旧档缺字段兼容。矿洞624×264保留原矿脉并新增30处铁矿，镜头跟随；详细接口和操作见新模块README与根README。

## 西岸森林接入

完整会话新增forest字段，保存在线计时、草药刷新期限/已采集状态与占用排除位置，恢复由forest.restore接入。旧档缺少该字段时初始化森林状态，原角色、物品、采集数据与坐标保持。

0.10.0完整快照包含onboarding，和foraging的拾取轮次同步保存及恢复；原有存档缺指引记录默认不启用，缺轮次上限保持历史补充规则。
