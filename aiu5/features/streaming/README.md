# 分区运行与独立全图

`streaming.gd.start(session)` 接入世界和领域模块；`focus` / `ensure_actor` 根据当前可操控角色选择活动区域，`set_overview` 控制独立地图与SceneTree暂停。主入口只注入和启动。

固定320×200区块，附近3×3模拟，地面两圈预加载并保留边界缓冲。对象立即入树的判定按相机真实可见范围计算（640×400视口 ÷ `world.camera.zoom`，外围再留64），不再假定一屏正好是一个区块；室外相机改为0.9倍后视野约711×444，仍完整落在3×3模拟区与`render_region`内。`terrain_chunk.gd` 按坐标确定性生成局部绘图，当前视野同步准备，其他由village/terrain每帧最多2块、2毫秒软预算准备；对象队列每帧最多4个、2毫秒软预算。非活动对象退出场景树但保留稳定状态节点与资源，不保证全部内存释放；逻辑障碍仍供导航与建造使用。

`overview.gd` 将地理与建筑、部署物、田块缓存为432×288纹理；静态签名改变才重建，人物标记在打开时快照。M/Esc输入由ALWAYS会话处理；世界隐藏且所有在线计时暂停，关闭不追赶。远区计时由领域模块结算，保存前flush部分秒数。验证见streaming_smoke与performance_probe。

全图按当前存档的world.homes标出所有房屋名称，并标出水井、猪圈、牛棚、祭台、祭坛和矿洞。文字采用深色底与连接建筑的引线，布置时避开建筑图形和其他名字；新村落只显示实际存在的三间房屋。标签与地形缓存同步重建，建筑名字/位置/尺寸变化会使签名失效，重复打开复用标签，不加载远处场景。


world_resources与focus同步：外两圈准备资源描述、近3×3建立物件，超过两圈释放节点并保留采集数据。资源模块拥有procedural_resource标记的节点，streaming不再次登记，避免两个所有者重复释放。资源模块另外每帧最多1块数据/2个节点，2ms软预算；全图暂停时队列也停。

建筑更新：construction拥有建筑台转化、动态房间与建筑生命/百分比减伤，production拥有T合成、V铁桶装沙与灶台30秒冶炼，combat拥有J弓箭及3名击败后不刷新的外部落敌人。UI通过workshop快照/操作信号请求，不计算材料与伤害；main仅组合。动态房屋/废墟加入world.homes及全图名字缓存，自建房屋附近保留3×3碰撞/敌人，远处停用；箭楼屋顶在世界坐标显示并可射箭。建筑、冶炼与敌人状态同时进入自动/祭台存档，旧档缺字段兼容。矿洞624×264保留原矿脉并新增30处铁矿，镜头跟随；详细接口和操作见新模块README与根README。

## 西岸森林接入

森林接入focus，地面区块x=-8..7，y=0..7；地图由overview.project映射负坐标，等比例绘出两侧地貌，建筑标签避让，草药屋自动标注。简图不创建远区林木，M仍暂停forest在线时钟。

全图新增铁匠铺、青木村四房及青木祭台标注；只读取固定坐标，打开地图不实例化远处房间或树木。
