# 角色生存状态

`vitals.gd` 的 `start(world, inventory)` 初始化每名可操控角色；`ensure(id)` 返回独立状态，`advance(seconds)` 只更新当前操控者的独立操控秒数，`use_food(id, item)` 只允许当前操控者原子消费食物或饮水。生命、饥饿、饥渴与健康初始上限10（木系一级生命11）。魔力初始10点，上限为10＋（魔法等级－1）×5；每升一级上限增加5点，升级不直接补充当前魔力。当前操控的存活角色每60在线秒恢复1点，满值停止累计；暂停、离线、阵亡和未操控角色不推进恢复，切换与保存保留未满一分钟的进度。旧存档保留当前魔力，缺少恢复计时默认为0。只有当前操控者推进生存计时，其他角色五项值与所有生存时钟锁定。旧档缺少魔力时补10，旧生肉历史沿用存档online时钟迁移到独立active_time，保留剩余窗口。无world的纯规则测试允许推进测试状态，180秒消耗、10秒低饥饿/饥渴伤害、低健康入区伤害与1800秒死亡、600秒生肉窗口及跑速疾病规则由本模块拥有。`export_state()` / `restore()` 保存部分计时和疾病历史。`deaths_changed` 交给存档模块处理切换或全员回退；UI只展示会话提供的状态。具体物品效果与疾病恢复规则见根README。

有水水桶每次降低1/4水量并恢复饥渴4格；满木杯一次喝完、恢复4格并返回空木杯。容器状态由inventory的`water_catalog.gd`给出，库存交换成功后才恢复状态，满21格也可等量换回容器；饥渴10或角色阵亡时不消耗。数值最多恢复到10。只有homestead处理取水/灌溉，UI不计算水量。

统一simulation/clock每0.5秒调用advance，操作/存档前flush部分时间；clock_driven防止双跑。全图暂停不扣状态，B/C/F菜单和普通室内外游玩继续推进，180秒/10秒/1800秒规则保持。

`revive(id)`只接受已经登记的阵亡角色，将五项状态重置10并清除疾病和计时债务，重新同步碰撞与跑速；献祭成本、空间和持久化由altar_display/offerings协调。切换角色前simulation.flush只结算上一操控者，切回来不补扣。

## 西岸森林接入

新增restorative_soup使当前存活角色生命/健康=10，qi_soup使生命+3/健康+5，上限10。低健康期限随恢复重置，健康>=7解除肠胃炎；B入口由forest.drink_soup协调保存及失败回滚，不影响其他角色，不复活死者。

苹果apple与胡萝卜carrot各消耗1个恢复饥饿2，上限10，沿用当前角色校验；普通物品，不增加魔法标记。

max_mana(id)向UI与存档提供等级上限；_recover_mana只在存活操控者的advance中恢复，mana_recovery_time随export_state/restore持久化。

## 皮装备防御

皮盔甲、皮护腿、皮头盔、皮靴每件防御1、免伤5%；只计算已穿戴到正确部位的物品，四件防御4、免伤20%。普通与赐予实例效果相同，背包和柜箱内物品不提供防御。皮装备之间相加，水系四级水盾按剩余伤害再减30%，满套＋水盾总免伤44%，原伤害10实际扣5.6生命。换装立即更新，存档重载按装备推导，不新增可累加的存档字段。铁装备防御3／2／2／1，满套40%；普通总减伤封顶50%，石阵之后再减10%剩余伤害，合计最高55%。

## 魔法分支接入（0.8.0）

伤害hurt(id,raw,context={})支持近战／远程／元素／敌人来源；减伤后由magic.branches吸收最强护盾、反伤及余烬保护。heal仍按角色生命上限封顶。范围恢复在分支模块执行，只推进当前操控角色，暂停／离线不推进。
