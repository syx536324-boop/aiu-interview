# 弓箭与外部落来袭者

`combat`管理J攻击、按武器区分的冷却和3名固定外部落敌人；`arrow`用360单位/秒飞行与扫掠射线检测命中，避开高速穿透，遮挡物拦截箭矢；`enemy`管理附近追击和攻击。素材复用Ninja Adventure原始人物图，红色血条/三角标识敌方。弓需装备到当前角色武器框，单箭原伤害10，每次有效发射消耗背包1支箭；仅地表和箭楼可射击，目标必须在实际视口内，房内及打开操作面板时不攻击。

初始敌人位置为(1200,950)、(1550,1100)、(1750,900)，各30生命。110单位内追击当前角色，受击追击6秒，移动32单位/秒；近身每2秒攻击一次，角色生命扣1，驻守自建建筑受到原伤害10再按建筑防御减伤。不修改未操控角色的五项状态。远区由streaming停用，没有全图寻路。暂无部落外交；击杀任何生物获得25魔法点。

击败后隐藏并取消碰撞/模拟，死亡、坐标和剩余攻击计时进入每份村落存档，经过时间或重新加载区块/游戏不会刷新。M全图用红点显示存活敌人，打开时全部暂停。主动回退或全员死亡恢复祭台历史快照，按该快照恢复敌人状态，这是原回退规则。

start(session)、fire(world_target)、hit_enemy(enemy, raw)、demolish、export_state/restore为契约；message向session发出反馈。屋顶射击排除自身房屋/女墙碰撞，其他墙体仍遮挡，角色退出/读档清理未命中的飞箭。main只组合，UI不实现战斗伤害。


武器框：画面下方偏右单格武器位，每个角色独立保存。点击空框打开背包，选镐子、斧、剑或弓后点“装备武器”；点击已装备框卸回背包（背包满则保留）。J使用已装备武器进行攻击。magic.equip_weapon负责原子物品交换及保存失败回滚，weapon_snapshot向HUD提供显示数据，session协调操作，main只连接信号。旧存档缺weapon时为空，背包内弓箭仍保留。


武器与工具更新：weapon_catalog定义镐子1、木剑1、石剑3、铁剑5、石斧2、铁斧4、弓1的基础攻击及分类，并定义每件武器的 `RANGES`（攻击距离，世界像素）与 `INTERVALS`（攻击间隔，秒）：镐子/两种斧/三种剑30·1，两种刀20·0.4，弓200·1。单格装备支持这些武器，equip_weapon仍原子交换并持久化。木斧从物品表移除，inventory._sanitize_slots和magic.restore_state将旧木斧转换为石斧。必须装备镐子采矿、装备斧砍树；桑树空手E采叶，持斧E砍树，其他武器不能采叶。森林树木沿用每2次1木头、4次砍完，resource_hits保持稳定ID，重载不复原。J近战沿用当前武器距离、间隔、视线和朝向检查；弓每次成功发射扣背包1箭，失败不扣；X拆自建房按当前斧攻击和房屋防御计算。

## 右键点击攻击

装备武器后，右键点击敌人即 `attack_clicked(at)`：命中测试只取鼠标下的那一具目标身体框，不会改打附近的另一只敌人；随后依次检查攻击距离（恰好等于距离算命中，超出即提示“目标超出武器攻击范围”）、目标在当前视口内、以及视线射线未被墙体和障碍拦截。室外相机为0.9倍且角色居中，640×400视口显示711×444世界像素，所以弓的200像素射程在上下左右都不会先被屏幕边界截断。弓走 `fire()`，其余武器走 `_melee()`，两者成功后都把冷却设为该武器自身的 `interval`，因此点击一次即进入该武器的攻击间隔。背包、赐予界面、属性面板、布置模式、全图或暂停期间一律不发动攻击；空地点点击和被遮挡目标都不消耗攻击也不消耗耐久。

## 耐久契约

durability.gd的normalize/consume/describe统一40格、15次扣1格规则，损坏后拒绝使用。combat成功挥击或发射只调用一次magic.consume_weapon；近战空挥计数，箭命中不再次计数。耐久、箭和近战伤害一并交给production.commit，失败恢复完整快照。第600次仍产生攻击。durability_smoke和arms_smoke验证这些边界。

## 击杀牛

J近战在相同武器距离、朝向和遮挡规则下可选中牛，箭扫掠加入动物碰撞层4；猪、牛、羊、鸟和狗均可被攻击击杀。近战牛伤害/皮革与本次武器耐久同事务，失败不扣；弓发射时已消耗箭与一次耐久，命中牛不二次扣，满包不能领取全部掉落时取消该次致命伤害。arrow保存原射手ID，飞行期间切换角色不改变皮革归属。leather_smoke覆盖实际挥击/箭命中、满包、失败回滚、死亡续玩、祭台与射手归属。

## 生物击杀

猪、牛、羊、鸟、狗和敌人均可被近战/箭命中，致死命中才奖励25魔法点，不重复计奖。掉落、死亡、经验、近战耐久同事务提交。箭传递发射角色ID，奖励与掉落不会归给切换后的操作者。

## 部落与态度

森林与野蛮两个部落各 20 人：12 平民、4 弓箭手、4 冲锋手，另有村长；成员是敌人型 actor，不占用可操控居民名额。野蛮部落敌对，进入视野 210 世界像素即追击攻击；森林部落态度未知，只在本方成员 80 世界像素内反击；平民仅 60 像素内自卫；弓箭手与村长远程距离 160／200。成员被限制在各自领地（青木村、北部高原），因此不会越界主动进攻赤沙村。村长按玩家规则配置 9 级魔法：森林村长木属性、野蛮村长火属性，均点亮前四个主干技能，魔力上限 50（10＋(9−1)×5），野蛮村长按玩家规则消耗与恢复魔力。验证：tests/tribes_smoke.gd。

## 0.7.6 维护

新增成员读档使用start阶段记录的各自初始位置及生命上限，不再查询仅含三名旧来袭者的SPAWNS表。旧档缺少成员数据时采用该成员的生成状态；已有坐标、受伤、阵亡和冷却记录继续保存。tests/tribal_restore_probe.gd验证空档、旧档、异常坐标与完整重载。

## 魔法分支接入（0.8.0）

敌人移速使用branches.speed_rate，主干与分支禁锢共享限制。伤害observe_hit支持石化累计20伤害提前解除。敌人近战／远程携带伤害上下文，村长携带觉醒元素；壁垒拦截射线和玩家箭的扫掠线段。防御、反伤与余烬属于magic／survival，不在UI计算。

## 0.8.1接口与规则

weapon_catalog定义石刀2、铁刀4；magic_scissors攻击3、范围80、interval(item,distance)在40像素分界取0.5／1秒。combat只接受实际敌人且无遮挡；scissors_flight负责扫掠命中、自动回收及飞行持久化，scissor_visual显示轨迹与回收。attack_damage和weapon_enchants接口来自magic，保存失败回滚耐久、护盾、冷却与飞行。

## 0.10.3计划复核

普通攻击、职业招式和村长效果使用实际目标与生命池；NPC对NPC命中不再写入无关vitals生命。起手锁定目标，合法遮挡和范围复核后落地。压制箭复用tribes/projectile.gd的正常逐帧扫掠箭，在命中后登记同来源20%减速；飞箭随正常读档清理。NPC技能公共间隔1秒，各招保留8／10／12／20秒独立限制；友方战士与弓箭手通过war接入同一职业招式。
