# 村民与猪

`resident.gd` 负责碰撞、四向动画、玩家移动和非操控村民的短距离巡游。由村落传入名字、贴图与路线，通过 `set_controlled()` 切换控制。

`resident_id` / `role_label` / `can_control` 标记身份与操控资格；普通 NPC 的 `can_control=false`，即使收到控制请求也不接受玩家输入。`input_enabled` 让角色面板打开时停下当前人物。巡游受动态居民阻挡时会等待并换目标。

`room_id` 为空表示户外，在室内时记录房屋 ID。未操控的室内人物原地等候，避免使用户外巡游坐标。空间切换和相机由室内模块与会话处理，人物移动继续使用所在空间的真实物理碰撞。

角色以 16×16 为一帧，按贴图实际宽高读取帧数；同时支持标准七行素材和 OldWoman 的两行素材。

地图通过 `find_path(from, to)` Callable 提供避障路线，角色消费路径；玩家自由移动继续由物理碰撞约束。

`pig.gd` 负责猪圈内的活动，`feed()` 让猪走向食槽。移动范围限制在圈内，打开门后也不会自行跑出。角色只负责移动与表现，取水、浇灌等状态归村落会话管理。


animal.gd统一猪牛移动、像素动画、公母颜色和幼崽缩放/成长条；pig.gd保留旧猪入口并继承它。animal_id/species/sex/growth/cooldown/fed是畜牧模块的数据，移动脚本不决定繁殖或增长时钟。

## 活动区域

远处角色、动物由streaming退出场景树，停止物理、移动与逐帧脚本；选中角色确保重新挂载，室内角色由interiors管理。稳定ID和节点状态继续供领域及存档访问。成年动物性别标记和静态人物阴影避免每帧重绘，幼崽时间仍归livestock结算。

## 魔法分支接入（0.8.0）

magic_branches由magic.start注入；自身受到禁锢或施放大地之拥时停止移动，技能状态与时间由魔法模块管理。


# 角色物理与动画

resident.gd的configure／set_controlled接受外部装配与控制状态，在物理帧处理输入、碰撞和四向动画；魔法减速同时作用于正常走路和跑步。跟随中的角色执行tribes.workers.movement的已授权移动意图，经营与战斗时间仍由Simulation推进。animal.gd保留动物自己的移动与动画，出生、掉落和牵引由相应领域配置。main只装配模块。
