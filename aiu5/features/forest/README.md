# 西岸森林与草药

森林为Rect2(-2400,0,2400,1600)，与原2400×1600沙漠等大。保留旧村落坐标，整体范围为x=-2400..2400、y=0..1600。四座现有河桥连接两侧，草药屋在(-260,240)，门口(-228,294)，林间道路连接各桥。

`forest.gd.start(session)`接入组合入口，`focus(at, indoors)`由streaming调用；两圈准备描述、附近一圈创建对象，每帧最多准备1区块、创建2对象并执行2ms软预算。种子及稳定ID决定林木和草药位置，避开道路、草药屋、地图边界与玩家部署。离远释放实体，仅保存采集/刷新记录和被部署物占用的位置。`plant.gd`负责像素林木、草药及桑叶外观，树干有碰撞。

`gather(id)`供E交互，采集一份相应物品；背包满不采集。桑树不消失，桑叶120在线秒恢复。人参/灵芝的每个生长位置每120在线秒独立以3%概率生成一份，未采集的保留且不叠加。采用几何等待时间采样，等价于逐期伯努利判定，远区无需逐帧遍历；初次生成也按3%判定。枸杞暂不自动再生。`elapse(delta)`由统一clock推进，M全图/Esc暂停与离线不推进。`export_state/restore`保存在线时钟、各位置的下一次刷新时间/采集状态以及占用排除记录；自动档与祭台回退均接入。

草药屋可进入，有木柜、木箱、桌椅和可布置工作台；工作台旁E/T通过现有production/Workshop合成界面展示catalog.gd配方，确认后制作60秒：人参1＋灵芝1＋满水木杯1→大补汤1＋空木杯1；枸杞1＋桑叶1＋满水木杯1→补气汤1＋空木杯1。只接受water_cup，桶/空杯不可替代，物品全部原子交换。

`drink_soup(item)`由B背包使用转交，Vitals执行生命/健康效果：大补汤两项回满10；补气汤健康+5、生命+3，上限10。保持其他角色冻结，不复活死者。恢复健康会按现有规则清除低健康死亡期限，健康达到7解除肠胃炎。采集、合成、喝汤均通过production.commit保存，写入失败恢复完整操作前状态。

组合入口scenes/main.gd只注册模块、连接信号，Session转交交互，规则与UI分离。全图使用简图与种子标记描绘森林，不实例化远区。验证入口tests/forest_smoke.gd覆盖桥梁/碰撞/负坐标寻路、加载预算、概率、在线时间/暂停/重启/祭台、采集与树木保留、汤剂配方/效果/水杯返还、满包和保存失败回滚。

generate(cell) 排除 Layout.FOREST_VILLAGE 整块青木村空地及新增连接道路，不在NPC巡逻点和房屋之间生成树木/草药，既有资源ID及已采集数据不重置。


武器与工具更新：weapon_catalog定义镐子1、木剑1、石剑3、铁剑5、石斧2、铁斧4、弓1的基础攻击及分类。单格装备支持这些武器，equip_weapon仍原子交换并持久化。木斧从物品表移除，inventory._sanitize_slots和magic.restore_state将旧木斧转换为石斧。必须装备镐子采矿、装备斧砍树；桑树空手E采叶，持斧E砍树，其他武器不能采叶。森林树木沿用每2次1木头、4次砍完，resource_hits保持稳定ID，重载不复原。J近战29单位、0.6秒间隔、视线和朝向检查；弓每次成功发射扣背包1箭，失败不扣；X拆自建房按当前斧攻击和房屋防御计算。

## 砍树耐久

普通树与桑树成功砍击均消耗已装备斧的1次使用，木头奖励、永久采集进度和耐久一起保存，失败全部回滚。空手采桑叶不消耗武器耐久，损坏斧不能砍树。

## 草丛种子

每块森林草丛每120在线秒20%概率生成1个小麦或水稻种子，类型等概率；未采集的保留、不叠加，采集后重新等待。seed_patches.gd使用几何等待采样等价的独立周期判定，远区不逐帧循环。稳定ID、待采种类和期限进入存档，卸载/重载不能刷新结果。原林木/草药ID不变。

## 0.7.6 维护

北侧森林的描述生成和加载窗口均覆盖y=-8..7区块；北侧仍沿用原森林资源种类、稳定ID和在线采集规则。tests/north_forest_probe.gd验证真实加载、六种资源及采集后重载。
