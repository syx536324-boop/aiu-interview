# 新手指引

仅新建 `starter_v2` 存档启用，旧存档缺记录时保持关闭。`onboarding.gd` 保存真实拾取木头2/石头4、工作台实际交付石斧/镐子、采尽一次矿脉的阶段；单纯背包拥有、赠送或未完成制作不会推进。三个可控角色共同完成，完成后隐藏。

`record_pickup`、`record_craft`、`record_mining` 由组合入口连接领域信号。事件在原保存事务内更新，材料、产物、矿脉与指引进度一起保存；失败随完整快照回滚。`presentation` 提供目标和阶段，`view.gd` 只绘制HUD小面板及方向提示，地图、背包、工作台等大面板出现时隐藏。`export_state/restore` 接入自动/祭坛快照，读档续接，离线及暂停不推进任何目标。

验证：`tests/onboarding_probe.tscn` 使用独立环境路径，通过真实拾取、制作确认、在线完成、装备与采矿接口检查限额、事务失败、重启和完成隐藏。游戏启动命令见根README。

## 六阶段教程

保留真实拾取、制作与采矿目标，再讲解魔法属性（建议不同角色选不同属性）、相机赐予和本方成年NPC升级。后三章可点击“已了解”，或访问对应界面自动记录，不强迫相机授权或消耗升级材料。`record_feature/acknowledge/review_features`是领域接口；进度随保存事务回滚，v1记录保留原成果。手机“更多→教程”、电脑版F1可重新查看功能章；缺历史记录时不强制显示。
