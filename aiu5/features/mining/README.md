# 矿洞与矿脉

mining.start连接世界、室内和库存；cave_catalog按保存的种子生成1920×960世界像素矿洞，划分6×4区块，每块320×240，每区块两处石矿，煤矿40%、铁矿10%独立判定。underground负责房间、相机和暗色场景，并按相机范围绘制地面；ore负责外观与碰撞。

装备镐子靠近E采集，石矿3次→石头3、煤矿3次→煤矿3、铁矿4次→铁矿2；每次间隔0.35秒。损坏、满包或保存失败不扣耐久、不丢奖励。采尽永久清除；export_state/restore保存种子、稳定矿脉ID和击打进度。旧存档42处矿脉保留原ID及进度，不重新抽取。

新角色没有赠送镐子，地表拾取首份木石，在公共工作台以木1石2制作，60在线秒。铁矿在炉中30秒冶炼粗铁。矿洞支持部署和保存篝火，E开关，照亮96×96世界像素。mining_smoke及elemental_smoke覆盖采集、旧档、概率分布、煤矿耗尽及篝火重载。
