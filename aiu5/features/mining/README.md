# 矿洞、矿脉与镐子制作

`mining.gd.start(world, interiors, inventory)` 在东山脚建立入口（2070,450），通过室内模块的特殊房间工厂创建地下空间；地表十处石矿，地下六处石矿、六处铁矿。携带镐子靠近E采集：石矿3下得石头3，铁矿4下得铁矿2，采尽清除碰撞、不自动刷新。最后一击背包满时不推进、不丢产物；每次击打间隔0.35秒。B使用镐子也可采附近矿。

镐子配方归production：木头1＋石头2→镐子1。室内或户外部署工作台后，靠近E打开分类界面、选择镐子并确认，60秒完成；缺材料或空间时不扣材料。此前已发放的初始镐子继续保留，新游戏也沿用初始装备，避免获取首份石头受阻。铁矿可在灶台或铁匠炉30秒冶炼为粗铁。

`export_state` / `restore` 管理各稳定矿脉ID的击打进度；地下房间、角色位置、物品通过完整存档保存，旧存档新增完整矿脉，祭台回退复原矿物与碰撞。`ore.gd` 只负责矿脉外观和碰撞，`entrance.gd` 只画入口，`underground.gd` 复用室内出入口/相机协议。地下暂不布置家具。验证：`tests/mining_smoke.gd`。


add_procedural(record)接入生成石矿，procedural与原surface固定十矿分开；采集条件和产量复用strike。restore保留所有gen1石矿进度，包含未加载/已耗尽区块；生成模块按需创建节点并读回hit。地下矿脉不受随机种子影响。

建筑更新：construction拥有建筑台转化、动态房间与建筑生命/百分比减伤，production拥有T合成、V铁桶装沙与灶台30秒冶炼，combat拥有J弓箭及3名击败后不刷新的外部落敌人。UI通过workshop快照/操作信号请求，不计算材料与伤害；main仅组合。动态房屋/废墟加入world.homes及全图名字缓存，自建房屋附近保留3×3碰撞/敌人，远处停用；箭楼屋顶在世界坐标显示并可射箭。建筑、冶炼与敌人状态同时进入自动/祭台存档，旧档缺字段兼容。矿洞624×264保留原矿脉并新增30处铁矿，镜头跟随；详细接口和操作见新模块README与根README。


武器与工具更新：weapon_catalog定义镐子1、木剑1、石剑3、铁剑5、石斧2、铁斧4、弓10的基础攻击及分类。单格装备支持这些武器，equip_weapon仍原子交换并持久化。木斧从物品表移除，inventory._sanitize_slots和magic.restore_state将旧木斧转换为石斧。必须装备镐子采矿、装备斧砍树；桑树空手E采叶，持斧E砍树，其他武器不能采叶。森林树木沿用每2次1木头、4次砍完，resource_hits保持稳定ID，重载不复原。J近战29单位、0.6秒间隔、视线和朝向检查；弓每次成功发射扣背包1箭，失败不扣；X拆自建房按当前斧攻击和房屋防御计算。

## 耐久事务

每次成功采矿消耗已装备镐子的1次使用，与采集进度和最后一击奖励一起提交；损坏、冷却、距离、满包或保存失败不扣。回滚可能重建地下矿物，失败后立即返回，不继续操作旧节点。durability_smoke覆盖第15次与写入失败。

工作台配方/60秒任务统一移交production；旧即时craft_pickaxe入口已删除，采矿仍需装备镐子。
